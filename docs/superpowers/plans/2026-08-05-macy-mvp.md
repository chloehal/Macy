# Macy — MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the smallest version of Macy that can be used on a phone every single day: log in with one password, open `/today`, move four sliders, flag a crise if there was one, save.

**Architecture:** Next.js App Router (TypeScript) writing directly to a MySQL database on Hostinger via Drizzle ORM + `mysql2`. No accounts — one shared password gates every route via a signed cookie checked in middleware. No `settings` table: the pack configuration (21 actifs / 7 arrêt / date de référence) lives in env vars read by `lib/config.ts`, because it changes roughly never and a UI for it is not what makes daily logging happen.

**Tech Stack:** Next.js 15 (App Router) · React 19 · TypeScript · Tailwind v4 · shadcn/ui · Drizzle ORM + `mysql2` · Zod · Vitest + React Testing Library · pnpm

## What this MVP deliberately leaves out

These come back once the app has been used daily for a week or two and there is evidence about what actually matters. The superseded plan `2026-07-07-macy-foundations-saisie.md` holds the detailed design for most of them.

- Couche 2 (saignement) and couche 3 (14 optional metrics, collapsible panel)
- `/settings` UI — config is env vars for now
- Smart pre-fill from the 14-day average — every field starts at the neutral 3
- Catch-up banner for a missing yesterday — the date is editable via `?date=`, that's enough
- PWA manifest / service worker
- `CHECK` constraints in the database — the API validates with Zod, and there is exactly one writer
- `/cycle` and `/trend`

## Global Constraints

These apply to every task below.

- **Rating scale is 1–5.** Neutral/default value is **3**. Polarity per metric is documented in the label, never enforced in code.
- **No user accounts.** One shared password (hashed, in an env var) protects a signed session cookie. No `user_id` column anywhere. `entries` is keyed by `date` alone.
- **Backend is MySQL on Hostinger**, via Drizzle ORM. Two databases on the same server: `macy` (production) and `macy_dev` (local dev + integration tests).
- **No dependencies requiring native binaries.** Password hashing uses Node's built-in `node:crypto` `scrypt` (no `bcrypt`). Session signing uses the Web Crypto API (no `jose`/JWT library) — `middleware.ts` runs on the Edge runtime, where `node:crypto` is unavailable, so the signing helpers must be Web Crypto and therefore `async`.
- **Copy is descriptive, never prescriptive.** No screen, label, or message may imply a verdict, judgment, or diagnosis. The `crise` marker is a neutral event marker — no red/alarm styling, no score.
- **Testing:** Vitest for pure logic and the database layer (run against the real `macy_dev` database — no mocking of MySQL), React Testing Library for component behavior. No E2E.
- **UX budget:** a "flat" day (accepting all defaults and saving) must be completable in **under 5 seconds**. Verified manually in Task 6.

```typescript
import { eq } from 'drizzle-orm';
import { db } from './client';
import { entries, type Entry, type NewEntry } from './schema';

export async function getEntryByDate(date: string): Promise<Entry | null> {
  const rows = await db.select().from(entries).where(eq(entries.date, date));
  return rows[0] ?? null;
}

export async function upsertEntry(input: NewEntry): Promise<void> {
  await db.insert(entries).values(input).onDuplicateKeyUpdate({ set: input });
}
```

```typescript
// lib/cycle/pack-day.ts
const DAY_MS = 24 * 60 * 60 * 1000;

function parseIsoDateUtc(date: string): number {
  const [year, month, day] = date.split('-').map(Number);
  // UTC volontairement : la différence entre deux dates civiles ne doit pas
  // dépendre du fuseau ni des changements d'heure.
  return Date.UTC(year, month - 1, day);
}

export function calcPackDay(
  date: string,
  dateDebutPlaquette: string,
  pilulesActives: number,
  joursArret: number,
): number {
  const cycleLength = pilulesActives + joursArret;
  const elapsedDays = Math.round(
    (parseIsoDateUtc(date) - parseIsoDateUtc(dateDebutPlaquette)) / DAY_MS,
  );
  return (((elapsedDays % cycleLength) + cycleLength) % cycleLength) + 1;
}
```

```typescript
// lib/auth/password.ts
import { scryptSync, randomBytes, timingSafeEqual } from 'node:crypto';

const KEY_LENGTH = 64;

export function hashPassword(password: string): string {
  const salt = randomBytes(16);
  const hash = scryptSync(password, salt, KEY_LENGTH);
  return `${salt.toString('hex')}:${hash.toString('hex')}`;
}

export function verifyPassword(password: string, stored: string): boolean {
  const [saltHex, hashHex] = (stored ?? '').split(':');
  if (!saltHex || !hashHex) return false;

  const expected = Buffer.from(hashHex, 'hex');
  if (expected.length !== KEY_LENGTH) return false;

  const candidate = scryptSync(password, Buffer.from(saltHex, 'hex'), KEY_LENGTH);
  return timingSafeEqual(candidate, expected);
}
```

```typescript
// lib/auth/session.ts
// Web Crypto plutôt que node:crypto : ce module est importé par middleware.ts,
// qui tourne sur le runtime Edge où node:crypto n'existe pas.
const SESSION_TTL_MS = 30 * 24 * 60 * 60 * 1000; // 30 jours
const encoder = new TextEncoder();

async function hmacKey(secret: string): Promise<CryptoKey> {
  return crypto.subtle.importKey(
    'raw',
    encoder.encode(secret),
    { name: 'HMAC', hash: 'SHA-256' },
    false,
    ['sign', 'verify'],
  );
}

function toHex(buffer: ArrayBuffer): string {
  return Array.from(new Uint8Array(buffer))
    .map((byte) => byte.toString(16).padStart(2, '0'))
    .join('');
}

function fromHex(hex: string): Uint8Array {
  const bytes = new Uint8Array(hex.length / 2);
  for (let i = 0; i < bytes.length; i += 1) {
    bytes[i] = Number.parseInt(hex.slice(i * 2, i * 2 + 2), 16);
  }
  return bytes;
}

export async function createSessionToken(
  secret: string,
  now: number = Date.now(),
): Promise<string> {
  const expires = String(now + SESSION_TTL_MS);
  const signature = await crypto.subtle.sign(
    'HMAC',
    await hmacKey(secret),
    encoder.encode(expires),
  );
  return `${expires}.${toHex(signature)}`;
}

export async function verifySessionToken(
  token: string,
  secret: string,
  now: number = Date.now(),
): Promise<boolean> {
  const [expires, signature] = (token ?? '').split('.');
  // HMAC-SHA256 = 32 octets = 64 caractères hexadécimaux.
  if (!expires || !/^[0-9a-f]{64}$/.test(signature ?? '')) return false;
  if (!/^\d+$/.test(expires)) return false;

  const valid = await crypto.subtle.verify(
    'HMAC',
    await hmacKey(secret),
    fromHex(signature),
    encoder.encode(expires),
  );
  if (!valid) return false;

  return Number(expires) > now;
}
```

```typescript
import { NextResponse } from 'next/server';
import { verifyPassword } from '@/lib/auth/password';
import { createSessionToken } from '@/lib/auth/session';

// Ce handler doit tourner sur Node : node:crypto (scrypt) n'existe pas sur Edge.
export const runtime = 'nodejs';

const SESSION_MAX_AGE_SECONDS = 30 * 24 * 60 * 60;

export async function POST(request: Request) {
  const { password } = (await request.json()) as { password?: string };

  if (!password || !verifyPassword(password, process.env.PASSWORD_HASH ?? '')) {
    return NextResponse.json({ error: 'invalid_password' }, { status: 401 });

  const token = await createSessionToken(process.env.SESSION_SECRET!);

  response.cookies.set('macy_session', token, {
    httpOnly: true,
    secure: process.env.NODE_ENV === 'production',
    sameSite: 'lax',
    path: '/',
    maxAge: SESSION_MAX_AGE_SECONDS,
  });
  return response;
```

```typescript
import { NextResponse, type NextRequest } from 'next/server';
import { verifySessionToken } from '@/lib/auth/session';

const PUBLIC_PATHS = new Set(['/login', '/api/auth/login']);

export async function middleware(request: NextRequest) {
  if (PUBLIC_PATHS.has(request.nextUrl.pathname)) return NextResponse.next();

  const token = request.cookies.get('macy_session')?.value;
  const isValid = !!token
    && await verifySessionToken(token, process.env.SESSION_SECRET!);

  if (!isValid) {
    return NextResponse.redirect(new URL('/login', request.url));
  }

  return NextResponse.next();
}
```

```tsx
// app/today/today-form.tsx
'use client';

import { useState } from 'react';
import { CoreSliders, type CoreValues } from '@/components/today/core-sliders';
import { Button } from '@/components/ui/button';
import { Label } from '@/components/ui/label';
import { Switch } from '@/components/ui/switch';
import { Textarea } from '@/components/ui/textarea';
import type { Entry } from '@/lib/db/schema';

const NEUTRAL = 3;

export function TodayForm({
  date,
  packDay,
  existingEntry,
}: {
  date: string;
  packDay: number;
  existingEntry: Entry | null;
}) {
  const [core, setCore] = useState<CoreValues>({
    noteGlobale: existingEntry?.noteGlobale ?? NEUTRAL,
    humeurBasse: existingEntry?.humeurBasse ?? NEUTRAL,
    energie: existingEntry?.energie ?? NEUTRAL,
    envieSucre: existingEntry?.envieSucre ?? NEUTRAL,
  });
  const [crise, setCrise] = useState(existingEntry?.crise ?? false);
  const [noteCrise, setNoteCrise] = useState(existingEntry?.noteCrise ?? '');
  const [notes, setNotes] = useState(existingEntry?.notes ?? '');
  const [status, setStatus] = useState<'idle' | 'saving' | 'saved' | 'error'>('idle');

  function markDirty() {
    setStatus('idle');
  }

  function handleCoreChange(key: keyof CoreValues, value: number) {
    setCore((previous) => ({ ...previous, [key]: value }));
    markDirty();
  }

  async function handleSave() {
    setStatus('saving');
    const response = await fetch('/api/entries', {
      method: 'POST',
      body: JSON.stringify({
        date,
        packDay,
        ...core,
        crise,
        noteCrise: crise && noteCrise ? noteCrise : null,
        notes: notes || null,
      }),
    });
    setStatus(response.ok ? 'saved' : 'error');
  }

  const formattedDate = new Intl.DateTimeFormat('fr-FR', {
    weekday: 'long',
    day: 'numeric',
    month: 'long',
  }).format(new Date(`${date}T12:00:00`));

  return (
    <main className="mx-auto max-w-md space-y-6 p-6 pb-24">
      <header className="space-y-1">
        <h1 className="text-lg font-medium first-letter:uppercase">{formattedDate}</h1>
        <p className="text-sm text-muted-foreground">Jour {packDay} de la plaquette</p>
      </header>

      <CoreSliders values={core} onChange={handleCoreChange} />

      <div className="space-y-3 border-t pt-6">
        <div className="flex items-center justify-between">
          <Label htmlFor="crise">Crise alimentaire</Label>
          <Switch
            id="crise"
            checked={crise}
            onCheckedChange={(value: boolean) => { setCrise(value); markDirty(); }}
          />
        </div>
        {crise && (
          <Textarea
            aria-label="Contexte de la crise"
            placeholder="Contexte (optionnel)"
            value={noteCrise}
            onChange={(event) => { setNoteCrise(event.target.value); markDirty(); }}
          />
        )}
      </div>

      <div className="space-y-2 border-t pt-6">
        <Label htmlFor="notes">Notes</Label>
        <Textarea
          id="notes"
          placeholder="Quelque chose à retenir de la journée (optionnel)"
          value={notes}
          onChange={(event) => { setNotes(event.target.value); markDirty(); }}
        />
      </div>

      <Button onClick={handleSave} disabled={status === 'saving'} className="w-full">
        {status === 'saved' ? 'Enregistré' : 'Valider'}
      </Button>
      {status === 'error' && (
        <p className="text-sm text-muted-foreground">
          L&apos;enregistrement n&apos;a pas abouti. Réessaie.
        </p>
      )}
    </main>
  );
}
```
